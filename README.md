# Vita Overdrive — VitaSDK starter

This repository currently contains a minimal PlayStation Vita homebrew smoke test and a GitHub Actions workflow intended to build a VPK.

## Build

Push to `main` or `master`, or run **Build Vita VPK** manually from the Actions tab. If the workflow succeeds, download the `VitaOverdrive-VPK` artifact from that run.

## Controls

Press START to exit.

## Current scope

This is only a build/startup test. It is not Terraria, Calamity, or the Desert Scourge implementation. Gameplay and original placeholder assets still need to be developed and tested on real Vita hardware.
